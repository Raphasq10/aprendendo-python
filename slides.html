1. Por que Python dominou o mundo?

Origem, filosofia de legibilidade, PEP 8 e Google Colab

Criado em 1991 pelo holandês Guido van Rossum, o Python não foi feito para ser a linguagem mais rápida em clock de processador, mas sim a mais rápida para o ser humano escrever e entender. O código foi desenhado para se parecer com o inglês comum falado.

💡
Analogia da Receita de Bolo: Enquanto linguagens como C++ e Java exigem que você monte uma fábrica inteira (com dezenas de chaves {} e pontos-e-vírgulas ;) só para fritar um ovo, em Python você só escreve o que precisa: fritar(ovo).
  • PEP 8: O manual sagrado de estilo do Python. Ele dita que usamos 4 espaços para cada indentação (afastamento de margem) e nomes em letras minúsculas separadas por underline (ex: minha_variavel).
  • Google Colab: É a ferramenta que usamos nas aulas! Roda tudo direto na nuvem do Google em "células" de código, sem precisar instalar nada na sua máquina.
🚨
Cai na Prova / Pegadinha Clássica: O Python é popular pela sua legibilidade e sintaxe amigável, e NÃO por ter tipagem estática (ele é dinâmico) ou por ter alta velocidade bruta de CPU.
🐍 python • Exemplo 01 
# Em Python, seu primeiro programa é uma única linha direta:
print("Bem-vindo à disciplina de Linguagem de Programação!")
print("Usando Python no Google Colab como vimos em aula.")
Terminal Output
Bem-vindo à disciplina de Linguagem de Programação! Usando Python no Google Colab como vimos em aula.

2. Variáveis, Tipos de Dados e F-Strings

Como guardar informações na memória e falar com o usuário

Uma variável é simplesmente uma "gaveta identificada" na memória RAM do computador onde você guarda um dado para usar depois.

📦
Os 4 Tipos Fundamentais de Dados:
  • int: Números inteiros, sem vírgula (ex: idade = 20, alunos = 45)
  • float: Números decimais com ponto, nunca vírgula! (ex: nota = 8.5, preco = 19.90)
  • str: Texto livre delimitado por aspas simples ou duplas (ex: curso = 'Python')
  • bool: Valor lógico booleano: apenas True ou False (com a primeira letra maiúscula!)
⚠️
O Perigo do input(): O comando input() SEMPRE devolve um texto (str)! Se você ler duas notas e fizer nota1 + nota2 sem converter, '5' + '5' vai virar '55'! Por isso precisamos de conversão de tipo (casting): float(input(...)).
🐍 python • Cálculo de Média com f-string 
# Exemplo prático da Aula 1 do professor:
aluno = "Lucas"
nota1 = 7.5
nota2 = 8.5

# Cálculo da média aritmética
media = (nota1 + nota2) / 2

# Interpolação moderna com f-string (PEP 498):
print(f"Estudante: {aluno} | Média Final: {media:.1f}")

# Validação se está aprovado (média mínima 6.0)
aprovado = media >= 6.0
print(f"Status Aprovado: {aprovado}")
Terminal Output
Estudante: Lucas | Média Final: 8.0 Status Aprovado: True

3. Comparações e Conectores Lógicos

Como o computador toma decisões lógicas

Para um programa decidir qual caminho seguir, ele avalia expressões lógicas que sempre resultam em True (verdadeiro) ou False (falso).

  • Operadores Relacionais: == (igual a), != (diferente de), > (maior), < (menor), >= (maior ou igual), <= (menor ou igual).
  • Atenção Vital: Um único sinal = é atribuição (guarda um valor na variável). Dois sinais == é comparação de igualdade!
  • Operadores Lógicos:
    • and (E): Só dá True se todas as condições forem verdadeiras.
    • or (OU): Dá True se pelo menos uma das condições for verdadeira.
    • not (NÃO): Inverte o resultado (transforma True em False e vice-versa).
🐍 python • Teste Lógico 
idade = 21
tem_carteira = True

# Para dirigir precisa de idade >= 18 E ter carteira
pode_dirigir = (idade >= 18) and tem_carteira
print(f"Pode dirigir legalmente? {pode_dirigir}")

# Meia entrada para cinema: menor de 12 OU estudante
estudante = True
idade_cliente = 25
tem_desconto = (idade_cliente < 12) or estudante
print(f"Tem direito à meia-entrada? {tem_desconto}")
Terminal Output
Pode dirigir legalmente? True Tem direito à meia-entrada? True

4. Condicionais e a "Regra da Peneira"

Dominando if, elif, else e a condição mais restritiva
🏺
A Famosa Analogia da Peneira do Professor: Imagine que você tem pedregulhos grandes e areia fina. Se você colocar uma peneira de buraco largo no topo, tudo passa direto e a peneira fina de baixo nunca é testada! Por isso, a condição mais difícil/exigente (mais restritiva) deve vir SEMPRE em primeiro lugar no if!
🐍 python • Exemplo da Peneira de Notas 
nota = 9.5

# FORMA CORRETA (Do mais difícil/restritivo para o mais brando):
if nota >= 9.0:
    classificacao = "Excelente (A)"
elif nota >= 7.0:
    classificacao = "Bom (B)"
elif nota >= 5.0:
    classificacao = "Regular (C)"
else:
    classificacao = "Reprovado"

print(f"Nota: {nota} -> Conceito: {classificacao}")
Terminal Output
Nota: 9.5 -> Conceito: Excelente (A)
🚨
Pegadinha Fatal de Prova: Se você colocasse if nota >= 5.0: logo no início, um aluno com nota 10 entraria direto no primeiro bloco e receberia "Regular", porque 10 é maior que 5! O Python para no primeiro True que encontrar.

5. Laços de Repetição: for e while

Automatizando repetições com range, break e continue

Em programação, nunca repetimos código manualmente. Usamos laços de repetição (loops):

  • for: Usado quando sabemos a quantidade de repetições ou quando estamos percorrendo uma lista de itens.
  • range(início, fim_exclusivo, passo): Gera uma sequência de números. Lembre-se: o número final nunca é incluído! Ex: range(1, 5) gera 1, 2, 3, 4.
  • while: Repete um bloco enquanto uma condição for verdadeira. Muito útil quando não sabemos quantas vezes o usuário vai tentar.
  • break: Chuta o balde! Interrompe o loop imediatamente e sai dele.
  • continue: Pula a rodada atual e vai direto para a próxima iteração.
🐍 python • Loops na Prática 
# Exemplo do professor: somando apenas números pares com continue
soma_pares = 0
for num in range(1, 11):
    if num % 2 != 0:
        continue  # Pula os ímpares
    soma_pares += num

print(f"Soma dos pares de 1 a 10: {soma_pares}")  # 2 + 4 + 6 + 8 + 10 = 30

# Exemplo com while e break:
contador = 1
while True:
    if contador == 4:
        break  # Sai do loop quando chegar a 4
    contador += 1
print(f"Parou no contador: {contador}")
Terminal Output
Soma dos pares de 1 a 10: 30 Parou no contador: 4

6. Funções (def) e Funções Lambda

Modularizando código e entendendo a pegadinha da prova

Uma função é um bloco de código nomeado com a palavra-chave def que faz uma tarefa específica. Evita copiar e colar código repetido.

⚙️
Diferença crucial: print() vs return O print() apenas joga uma mensagem na tela para um humano ler. O return devolve o resultado para dentro de uma variável, permitindo que você use esse valor para outros cálculos!
🐍 python • Funções Normais e Lambda 
# Função tradicional com def
def calcular_media(n1, n2):
    return (n1 + n2) / 2

# Função anônima (Lambda) em uma única linha:
# Sintaxe: lambda argumentos: expressao
dobro = lambda x: x * 2

print(f"Média calculada: {calcular_media(8, 10)}")
print(f"Dobro de 15: {dobro(15)}")
Terminal Output
Média calculada: 9.0 Dobro de 15: 30
🚨
ALERTA MÁXIMO DE PROVA DA FACULDADE: O gabarito oficial da prova considera que funções anônimas (lambda) são: "Funções que não têm um corpo definido", porque elas não possuem o bloco de comandos tradicional nem a palavra return explícita. Guarde essa frase com carinho!

7. Coleções: Listas vs Tuplas

Mutabilidade, métodos append/pop e indexação zero

Em Python, as coleções ordenadas começam a contagem de posições no índice 0 (o primeiro item fica em [0] e o último pode ser acessado com [-1]).

📊
A Diferença Fundamental:
  • Listas ([ ]): São MUTÁVEIS. Você pode alterar valores, adicionar itens com .append() e remover com .pop().
  • Tuplas (( )): São IMUTÁVEIS. Uma vez criadas, NINGUÉM pode alterar seus valores! Servem para garantir a integridade dos dados (ex: coordenadas GPS, dias da semana).
🐍 python • Listas vs Tuplas 
# Lista: permite alterações
compras = ["Arroz", "Feijão", "Azeite"]
compras.append("Macarrão")  # Adiciona ao final
compras[0] = "Arroz Integral"  # Altera o item 0!
print("Lista modificada:", compras)

# Tupla: blindada contra modificações
cores_rgb = (255, 128, 0)
print("Tupla:", cores_rgb)
# cores_rgb[0] = 100 -> Se tentar rodar isso, o Python lança um TypeError!
Terminal Output
Lista modificada: ['Arroz Integral', 'Feijão', 'Azeite', 'Macarrão'] Tupla: (255, 128, 0)

8. Conjuntos (Sets) e Dicionários

Itens únicos sem repetição e mapeamento chave: valor
  • Conjuntos (set): Coleção de dados que elimina itens duplicados automaticamente e não possui ordem fixa. Métodos principais: .add('item') e .remove('item').
  • Dicionários (dict): Estrutura fantástica de pares chave: valor. O acesso é feito diretamente pelo nome da chave entre colchetes.
🐍 python • Sets e Dicionários 
# Set: remove duplicatas de uma lista instantaneamente
emails = ["ana@gmail.com", "bob@gmail.com", "ana@gmail.com"]
unicos = set(emails)
print("E-mails únicos:", unicos)  # Apenas 2 itens!

# Dicionário: ficha cadastral completa
aluno = {
    "matricula": 1024,
    "nome": "Maria Silva",
    "curso": "Sistemas de Informação",
    "semestre": 3
}

print(f"Nome do Aluno: {aluno['nome']}")
print(f"Curso: {aluno['curso']}")
Terminal Output
E-mails únicos: {'ana@gmail.com', 'bob@gmail.com'} Nome do Aluno: Maria Silva Curso: Sistemas de Informação

9. List Comprehension (Compreensão de Listas)

O jeito Pythônico e elegante de transformar dados em 1 linha

Em outras linguagens você cria uma lista vazia, faz um loop for e vai dando append. Em Python existe uma sintaxe maravilhosa chamada List Comprehension que faz isso de forma direta e super veloz.

🐍 python • List Comprehension 
# Exemplo Oficial do PDF da Aula:
cores = ['AZUL', 'VERDE', 'AMARELO', 'VERMELHO']

# Modo Pythónico elegante (List Comprehension):
novas_cores = [c.lower() for c in cores]

print("Cores em minúsculo:", novas_cores)

# Filtrando apenas números pares ao quadrado:
numeros = [1, 2, 3, 4, 5, 6]
quadrados_pares = [n**2 for n in numeros if n % 2 == 0]
print("Quadrado dos pares:", quadrados_pares)
Terminal Output
Cores em minúsculo: ['azul', 'verde', 'amarelo', 'vermelho'] Quadrado dos pares: [4, 16, 36]
🚨
Questão Clássica de Exame: "Para converter todos os elementos de uma lista de cores maiúsculas para minúsculas de forma concisa, qual abordagem é recomendada?" -> Resposta: List Comprehension!

10. Computação Numérica com NumPy

Arrays multidimensionais, vetorização e alta velocidade

O NumPy (Numerical Python) é a biblioteca padrão que permitiu ao Python se tornar o líder mundial em Ciência de Dados e Inteligência Artificial.

  • Vetorização: Se você tentar fazer [1, 2, 3] * 2 em Python puro, a lista apenas duplica os elementos: [1, 2, 3, 1, 2, 3]. No NumPy, ele multiplica matematicamente cada número de uma só vez sem precisar de nenhum loop for!
  • Alta Performance: Os arrays do NumPy (ndarray) são escritos em C e guardam dados contíguos na memória RAM, sendo até 50x mais rápidos que listas comuns.
🐍 python • Vetorização com NumPy 
import numpy as np

# Criando um array do NumPy
vendas = np.array([100, 250, 300, 450])

# Aplicando 10% de comissão em todos os valores instantaneamente:
comissoes = vendas * 0.10

print("Vendas:", vendas)
print("Comissões calculadas:", comissoes)
print("Total vendido:", np.sum(vendas))
print("Média de vendas:", np.mean(vendas))
Terminal Output
Vendas: [100 250 300 450] Comissões calculadas: [10. 25. 30. 45.] Total vendido: 1100 Média de vendas: 275.0

11. Programação Orientada a Objetos (POO)

Classes, Objetos, Atributos e Métodos explicados sem complicação
🧁
A Analogia da Forma de Bolo:
  • Classe (class): É a forma de metal. Ela define o formato, os relevos e o tamanho.
  • Objeto: É o bolo real que você tira de dentro da forma depois de assar! Cada bolo pode ter uma cobertura diferente (chocolate, cenoura).
  • Atributos: As características (ex: cor, sabor, preço).
  • Métodos: As ações que ele realiza (ex: fatiar, esquentar).
🐍 python • Exemplo Completo de POO 
class Carro:
    # O método construtor __init__ inicializa os atributos do objeto
    # 'self' representa a própria instância que está sendo criada!
    def __init__(self, marca, modelo, ano):
        self.marca = marca
        self.modelo = modelo
        self.ano = ano
        self.velocidade = 0  # Começa parado

    # Método (ação do carro)
    def acelerar(self, valor):
        self.velocidade += valor
        print(f"{self.modelo} acelerou para {self.velocidade} km/h!")

# Instanciando (criando) os objetos reais:
carro1 = Carro("Toyota", "Corolla", 2024)
carro1.acelerar(60)
Terminal Output
Corolla acelerou para 60 km/h!
🚨
Afirmação de Prova: A POO permite modelar sistemas com base em entidades do mundo real através de atributos e métodos. Ela continua sendo um dos paradigmas mais fundamentais e modernos do desenvolvimento de software (não é obsoleta).

12. Herança em Python e Criação de Módulos

Reaproveitamento inteligente de código e importações

Herança é o mecanismo onde uma classe-filha herda automaticamente todos os atributos e comportamentos de uma classe-pai, sem precisar reescrever nada.

🐍 python • Herança na Prática 
# Classe Pai (Genérica)
class Animal:
    def __init__(self, nome):
        self.nome = nome

    def respirar(self):
        print(f"{self.nome} está respirando...")

# Classe Filha (Específica) herda de Animal
class Cachorro(Animal):
    def latir(self):
        print(f"{self.nome} diz: Au au!")

# Instanciando
rex = Cachorro("Rex")
rex.respirar()  # Método herdado do pai Animal!
rex.latir()     # Método exclusivo da classe Cachorro
Terminal Output
Rex está respirando... Rex diz: Au au!

Módulos em Python: Todo arquivo .py criado por você é um módulo! O principal objetivo de criar módulos é organizar e reutilizar código em diferentes partes de um sistema.

13. Banco de Dados e o Diferencial do SQLite

Persistência embutida, operações CRUD e comandos DML

O SQLite é um banco de dados relacional (SQL) que já vem embutido na biblioteca padrão do Python através do módulo sqlite3.

🚨
O Grande Diferencial do SQLite na Prova: Ao contrário do MySQL ou PostgreSQL, o SQLite opera SEM a necessidade de um servidor de rede separado (ele é serverless) e armazena todo o banco de dados dentro de um único arquivo no disco (ex: meu_banco.db)!
🐍 python • Banco de Dados SQLite (CRUD) 
import sqlite3

# Conecta ao arquivo (cria se não existir)
conn = sqlite3.connect(':memory:')  # Usando memória RAM para teste rápido
cursor = conn.cursor()

# DDL: Criando a tabela
cursor.execute('''
    CREATE TABLE alunos (
        id INTEGER PRIMARY KEY,
        nome TEXT,
        nota REAL
    )
''')

# DML (INSERT): Inserindo registros
cursor.execute("INSERT INTO alunos (nome, nota) VALUES ('Carlos', 9.5)")
cursor.execute("INSERT INTO alunos (nome, nota) VALUES ('Juliana', 8.0)")
conn.commit()

# DML (SELECT): Lendo os dados salvos
cursor.execute("SELECT nome, nota FROM alunos")
for linha in cursor.fetchall():
    print(f"Aluno: {linha[0]} | Nota: {linha[1]}")

conn.close()
Terminal Output
Aluno: Carlos | Nota: 9.5 Aluno: Juliana | Nota: 8.0

Comandos DML (Data Manipulation Language): SELECT, INSERT, UPDATE, DELETE. São os que manipulam os dados nas linhas das tabelas.

14. Análise de Dados com a Biblioteca Pandas

Series vs DataFrames e a regra das chaves como índices

O Pandas (import pandas as pd) é a ferramenta definitiva para trabalhar com dados tabulares em Python. Ele possui duas estruturas centrais:

  • Series: Estrutura unidimensional (uma coluna única com índices).
  • DataFrame: Estrutura bidimensional completa (uma tabela com várias colunas e linhas, como uma planilha do Excel).
🚨
Regra de Ouro da Prova (Series de Dicionário): Quando você cria uma Series do Pandas a partir de um dicionário (ex: {'SP': 1200, 'RJ': 900}), as chaves do dicionário tornam-se automaticamente os índices da Series!
🐍 python • DataFrame com Pandas 
import pandas as pd

# Criando um DataFrame a partir de um dicionário de listas
dados = {
    'Produto': ['Notebook', 'Mouse', 'Teclado', 'Monitor'],
    'Preco': [3500.0, 80.0, 150.0, 900.0],
    'Estoque': [10, 50, 35, 12]
}

df = pd.DataFrame(dados)
print("Tabela Completa:")
print(df)

# Média de preços
print("\nMédia de Preço:", df['Preco'].mean())
Terminal Output
Tabela Completa: Produto Preco Estoque 0 Notebook 3500.0 10 1 Mouse 80.0 50 2 Teclado 150.0 35 3 Monitor 900.0 12 Média de Preço: 1157.5

15. Manipulação e Limpeza com Pandas

Filtros, valores nulos e remoção de duplicados com drop_duplicates

Na vida real, bases de dados chegam cheias de falhas: linhas duplicadas, valores faltando e tipos errados. O Pandas possui funções prontas para higienizar tudo:

  • Remoção de Duplicados: O método oficial chama-se df.drop_duplicates().
  • Tratamento de Nulos (NaN): df.dropna() para jogar fora as linhas vazias ou df.fillna(valor) para preencher com um valor padrão (como a média ou zero).
  • Filtros Condicionais: df[df['idade'] >= 18] filtra apenas quem tem mais de 18 anos.
🐍 python • Limpeza de Dados 
import pandas as pd

dados_clientes = {
    'Nome': ['Ana', 'Bruno', 'Ana', 'Carlos'],  # 'Ana' está duplicada!
    'Idade': [28, 35, 28, 42]
}

df_raw = pd.DataFrame(dados_clientes)
print("Antes da limpeza (4 registros):")
print(df_raw)

# Removendo registros duplicados:
df_limpo = df_raw.drop_duplicates()
print("\nDepois do drop_duplicates() (3 registros):")
print(df_limpo)
Terminal Output
Antes da limpeza (4 registros): Nome Idade 0 Ana 28 1 Bruno 35 2 Ana 28 3 Carlos 42 Depois do drop_duplicates() (3 registros): Nome Idade 0 Ana 28 1 Bruno 35 3 Carlos 42

17. Desenvolvimento Web com Python

Front-end vs Back-end, HTTP e o confronto Flask vs Django

O Python é amplamente utilizado no desenvolvimento web, principalmente no Back-end (o cérebro do servidor que processa dados e regras de negócio).

  • Flask: Um microframework minimalista e ultra rápido. Ele não vem com banco nem painel forçados; você escolhe o que quer plugar. Muito usado para criar APIs REST e microsserviços.
  • Django: Um framework full-stack e robusto ("batteries-included"). Já vem com painel de administração pronto, sistema de login, ORM de banco de dados e proteção contra invasões.
🐍 python • Servidor Web Simples com Flask 
# Como criar uma rota web com Flask:
from flask import Flask

app = Flask(__name__)

@app.route('/')
def home():
    return "
Olá, Mundo! Minha primeira API em Python.
"

if __name__ == '__main__':
    # Roda o servidor local na porta 5000
    app.run(debug=True)
Terminal Output
* Serving Flask app '__main__' * Running on http://127.0.0.1:5000/ (Press CTRL+C to quit)

18. Desenvolvimento Mobile: Kivy e KivyMD

Criando aplicativos para Android e iOS e a navegação por abas

Para criar aplicativos de celular sem precisar de Java/Kotlin ou Swift, o ecossistema Python disponibiliza o Kivy e o KivyMD.

  • Kivy: Biblioteca com motor gráfico próprio para criar interfaces touch e multiplataforma.

🚨
Componente de Abas no KivyMD (Questão de Exame):
Para implementar uma interface moderna com navegação em abas no KivyMD, utilizamos o componente MDTabs!
🐍 python • Estrutura Básica de um App Kivy 
from kivy.app import App
from kivy.uix.button import Button

class MeuPrimeiroApp(App):

19. Testes de Software: doctest e unittest

Garantindo a qualidade do código e entendendo o if __name__ == '__main__'
  • doctest: Permite escrever testes diretamente dentro do texto de documentação (docstring) da função. Se o resultado retornado for diferente do exemplo, o doctest imprime na tela exatamente onde ocorreu a discrepância.
  • unittest: Framework profissional baseado em classes de teste (unittest.TestCase) com métodos de assertiva como assertEqual(a, b).
🚨
Para que serve o bloco if __name__ == '__main__': unittest.main()?
Ele garante que a suíte de testes seja executada apenas se o arquivo for rodado diretamente pelo terminal. Se esse arquivo for importado por outro módulo do sistema, os testes não vão disparar sozinhos!
🐍 python • Testes com unittest 
import unittest

def somar(a, b):
    return a + b

class TesteCalculadora(unittest.TestCase):
    def test_soma_positivos(self):
        self.assertEqual(somar(2, 3), 5)  # 2 + 3 deve ser 5!

    def test_soma_negativos(self):
        self.assertEqual(somar(-1, -1), -2)

if __name__ == '__main__':
    unittest.main(argv=['first-arg-is-ignored'], exit=False)

20. Machine Learning e TensorFlow

Os 3 tipos de aprendizagem e redes neurais com Keras
🤖
Os Três Pilares do Aprendizado de Máquina:
  • Aprendizado Supervisionado: O modelo aprende com dados rotulados contendo a resposta correta (ex: fotos de gatos e cães já identificadas; previsão de preços de imóveis com base no tamanho). Usamos model.fit(X_train, y_train).
  • Aprendizado Não Supervisionado: O modelo busca padrões e agrupamentos sozinho, sem respostas ou rótulos prévios (ex: agrupar clientes por perfil de compra).
  • Aprendizado por Reforço: Um agente interage continuamente com um ambiente dinâmico para maximizar recompensas através de tentativa e erro (ex: IA aprendendo a jogar xadrez ou videogame).

TensorFlow & Keras: Biblioteca do Google para Redes Neurais. Modelos Sequential usam camadas como Flatten (para achatar uma matriz/imagem em um vetor linear) e Dense (camadas densas totalmente conectadas de neurônios).
